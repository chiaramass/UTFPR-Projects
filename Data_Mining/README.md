# Data Cleaning & Exploratory Data Analysis (EDA)

This project focuses on preprocessing and exploring the Air Quality UCI dataset to clean anomalies and extract meaningful insights.

## 🎯 Project Objective
Identify and handle missing values and outliers

## 🛠️ Technologies Used
- **Libraries:** Pandas, NumPy, Seaborn, Matplotlib
##Steps
**Outlier Handling:** Detected data anomalies using statistical visual tools and replaced them by calculating clean feature means.
 **Statistical Visualization:** Created Box Plots, Violin Plots, and Histograms to understand data distributions and variance.
  **Correlation Analysis:** Built Heatmap using Seaborn to identify linear relationships between air pollutants and environmental factors (Temperature, Humidity).
- **Data Grouping:** Performed aggregation operations (`groupby`) to analyze pollutant concentrations by month and hour of the day.
